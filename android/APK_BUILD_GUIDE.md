# Step-by-step: Build the TC22R / RFD40 Android APK

This guide gets you from the Lovable project to a working `.apk` on a Zebra TC22R (or RFD40 sled).

## What you need installed

| Application | Purpose | Where to get it |
|-------------|---------|-----------------|
| **Android Studio** | Build the APK | https://developer.android.com/studio (Hedgehog or newer) |
| **JDK 17** | Java compiler | Bundled with Android Studio, or https://adoptium.net/temurin17 |
| **Node.js 20+** | Run Capacitor CLI | https://nodejs.org |
| **bun** (or npm) | Install JS deps | https://bun.sh (or use `npm`) |
| **Git** | Clone the repo | https://git-scm.com |
| **Zebra RFID3 SDK** | Native RFID driver | https://developer.zebra.com/rfid-sdk-android (API3 2.0.3.x or newer) |

You also need a **TC22R** device with USB debugging enabled, or an RFD40 sled docked to a TC22/TC27.

## 1. Get the project onto your machine

Export the project from Lovable to GitHub, then clone it:

```bash
git clone <your-github-repo-url>
cd <repo-folder>
bun install          # or: npm install
```

## 2. Add the Android platform

This creates the `android/` folder that Android Studio will open.

```bash
bunx cap add android
bunx cap sync android
```

> The app is server-rendered, so `dist/client` has no `index.html`. `capacitor.config.ts` already points the WebView at the published Lovable URL. The native RFID plugin still runs locally on the device.

## 3. Drop in the Zebra RFID3 SDK

Download the **Zebra RFID SDK for Android** from the Zebra developer portal.

Place these files in `android/app/libs/`:

- `API3_LIB-x.x.x.aar` (the main RFID3 SDK)
- `ASCII_SDK_API.jar` (if it is shipped alongside)

Then make sure `android/app/build.gradle` contains:

```gradle
dependencies {
    implementation fileTree(dir: 'libs', include: ['*.aar', '*.jar'])
    // ... other dependencies already generated by Capacitor
}
```

## 4. Copy the custom plugin

Copy the native plugin into the Android project:

```bash
# From the repo root
cp android-plugin/ZebraTC22RPlugin.kt \
   android/app/src/main/java/com/barcodewarehouse/uhftagfinder/ZebraTC22RPlugin.kt
```

## 5. Wire up the hardware trigger

Open the generated file:

```
android/app/src/main/java/com/barcodewarehouse/uhftagfinder/MainActivity.kt
```

Replace its contents with the snippet in `android-plugin/MainActivity.kt.snippet`. The key part is:

```kotlin
override fun onCreate(savedInstanceState: Bundle?) {
    registerPlugin(ZebraTC22RPlugin::class.java)
    super.onCreate(savedInstanceState)
}
```

and the `dispatchKeyEvent` forwarding for trigger keycodes `293`, `280`, `10036`.

## 6. Build the APK

Open Android Studio from the project:

```bash
bunx cap open android
```

In Android Studio:

1. Wait for Gradle sync to finish.
2. Choose **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
3. The APK will be written to:
   ```
   android/app/build/outputs/apk/debug/app-debug.apk
   ```

## 7. Install on the TC22R

Connect the TC22R via USB with USB debugging enabled, then run:

```bash
adb install android/app/build/outputs/apk/debug/app-debug.apk
```

Or use Android Studio: **Run → Run 'app'** with the device selected.

## TC22R-specific settings

Before the SDK can talk to the built-in reader:

1. **DataWedge** — for this app's profile, disable or undefine the **RFID input plugin / RFID trigger**. If DataWedge owns the trigger, the SDK cannot connect.
2. Keep **RFID Manager / Zebra RFID services** updated via LifeGuard updates.
3. Expect shorter read range than an RFD40 sled — the integrated antenna has lower maximum power.

## Testing Geiger search

1. Open the app and sign in.
2. Go to **Mobile Dashboard**.
3. Tap the **crosshair icon** on any scanned item row.
4. Pull and hold the **hardware trigger**. The proximity meter should move as you point the device toward the tag.
5. Release the trigger to stop locating.

## Update cycle

- **Web UI changes** (new pages, fixes, dashboard tweaks): publish/update in Lovable, then restart the app. No new APK needed.
- **Native plugin changes** (new Kotlin code, SDK changes, trigger handling): rebuild the APK and reinstall.

## Troubleshooting

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| "Scanner not on" / init fails | DataWedge owns the RFID trigger | Disable RFID input in the app's DataWedge profile |
| Build error `cannot find symbol com.zebra.rfid` | SDK AAR missing or not in `libs/` | Re-copy `API3_LIB-x.x.x.aar` and sync Gradle |
| App opens but no RFID reads | Wrong transport or trigger not forwarded | Check `MainActivity.kt` has the plugin registered and keycodes forwarded |
| Geiger meter does not move | Locationing not started or target EPC mismatch | Make sure the crosshair button armed the target EPC before pulling the trigger |
